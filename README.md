# PenguTunnel 5.0.4

بستهٔ فایل ارسالی مالک مخزن: **هستهٔ 5.0.4** و **منوی نصب 4.2.5** برای Linux x86_64/amd64.

## نصب یا به‌روزرسانی

روی سرور با دسترسی `root` اجرا کنید:

```bash
curl -fL --retry 3 https://raw.githubusercontent.com/V2grop/PenguTunnel/main/install-online.sh -o /root/pengu-install-online.sh && bash /root/pengu-install-online.sh
```

اگر curl نصب نیست، در اوبونتو:

```bash
apt-get update && apt-get install -y curl ca-certificates gzip
```

همان دستور قدیمی نیز کار می‌کند:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/V2grop/PenguTunnel/main/install-online.sh)
```

روش اول در صورت شکست دانلود، اجرای نصب‌کننده را شروع نمی‌کند و ترجیح داده می‌شود.

## بررسی دانلود بدون نصب

```bash
curl -fL --retry 3 https://raw.githubusercontent.com/V2grop/PenguTunnel/main/install-online.sh -o pengu-install-online.sh && bash pengu-install-online.sh --verify-only
```

این حالت هسته را اجرا نمی‌کند و تنظیمات سیستم را تغییر نمی‌دهد؛ فایل‌ها را دانلود و SHA256 را بررسی می‌کند و فایل‌های موقت را پاک می‌کند.

## رفتار به‌روزرسانی

- اسکریپت اصلی `install.sh` همان فایل ارسالی مالک مخزن است؛ منطق هسته تغییر نکرده است.
- نصب‌کنندهٔ آنلاین، فایل‌ها را از یک commit مشخص دریافت می‌کند تا نسخه‌های متفاوت با هم مخلوط نشوند.
- باینری 43,950,204 بایتی با gzip فشرده و در ۳۰ بخش داخل `releases/5.0.4/` ذخیره شده است. بازسازی کاملاً خودکار است.
- SHA256 اسکریپت، آرشیو و باینری بازسازی‌شده پیش از اجرا بررسی می‌شود.
- هسته در `/root/pengutunnel/pengutunnel` نصب می‌شود. اسکریپت ارسالی، پیش از جایگزینی هستهٔ متفاوت، از آن نسخهٔ پشتیبان زمان‌دار می‌سازد و سرویس‌های تونل فعال را مجدداً راه‌اندازی می‌کند.
- پیش از ارتقای سرور فعال، از تنظیمات `/root/pengutunnel` نسخهٔ پشتیبان بگیرید. ارتقای دو سمت تونل را هماهنگ انجام دهید؛ سازگاری تنظیمات و ارتباط بین نسخه‌های مختلف در این انتشار آزمایش نشده است.
- به‌روزرسانی خودکار از فروشنده در اسکریپت ارسالی غیرفعال است.

## محدودهٔ بررسی

نحو Bash هر دو اسکریپت و سناریوهای دانلود موفق، شکست دانلود، خرابی اسکریپت، خرابی آرشیو، رد آرگومان ناشناخته و پاک‌سازی فایل موقت با داده‌های محلی بررسی شده‌اند. SHA فایل‌های بارگذاری‌شده با محتوای محلی تطبیق داده شده است.

اجرای واقعی تونل روی Ubuntu 24.04 یا 26.04 در این محیط آزمایش نشده است. معماری ARM64 پشتیبانی نمی‌شود. تطابق SHA256 فقط یکسان‌بودن فایل را نشان می‌دهد و تضمین امنیت یا نبود رفتار مخرب در باینری بسته نیست؛ ممیزی کامل باینری انجام نشده است.
